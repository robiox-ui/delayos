Settings-only versions of the DelaySys row controls, measured against the reference Settings
(docs/ui-spec.md §8, docs/reports/settings-redesign/). They keep the DelaySys API and names;
a Settings page imports DelaySys first and this directory last, so these win.
Every file here ends its imports with `import "."` for the same reason.
Glyphs: ../glyphs (chevrons, search, close, nav-*).
